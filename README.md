### O que cada módulo cobre

- **Mundo 1:** `print()` e `input()`, variáveis e tipos, operadores, módulos `math` e `random`, f-strings, `if`/`else`
- **Mundo 2:** `elif`, laços `for` e `while`, `break` e `continue`, contadores e acumuladores
- **Mundo 3:** tuplas, listas, dicionários, funções e tratamento de erros com `try`/`except`

### Como rodar

Com Python 3 instalado:

```bash
git clone https://github.com/KairosMurilo/exercicios-python-desafios.git
cd exercicios-python-desafios/mundo-1-fundamentos
python ex001.py
```
